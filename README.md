# Jennifer Wiblishouser — Executive Marketing Portfolio

A responsive, single-page portfolio designed for GitHub Pages. No build tools or paid hosting required.

## Before publishing

1. In `index.html`, replace `https://www.linkedin.com/` with your actual LinkedIn profile URL.
2. Replace `YOUR_EMAIL@example.com` with your professional email address.
3. Review the metrics and language for accuracy and confirm you have permission to share the examples publicly.
4. When ready, replace the decorative `JW` illustration with a professional photograph and replace the video placeholder with your video embed.
5. Optional: Add a PDF resume, then link it from the navigation or contact section.

## Publish with GitHub Pages

1. Create a free GitHub account at https://github.com if you do not have one.
2. Create a **public** repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
3. Upload **the three website files** (`index.html`, `styles.css`, `script.js`) into the **root** of that repository. You can also upload this README.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
6. Once published, visit `https://YOUR-USERNAME.github.io`.

If you use a different repository name, your website address will generally be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Update later

Edit or replace the files in the GitHub repository. GitHub Pages republishes when the configured branch updates.

## Notes

- The design loads fonts from Google Fonts. If they are unavailable, fallback fonts are used.
- The video area is a placeholder and the LinkedIn/email buttons need real destinations.
- No form backend or tracking is included.
